# 인증

카카오 로그인과 자체 JWT 발급 방식이다. 모바일 확장을 고려해서 웹과 모바일을 같은 방식으로 처리한다. 회원 정책은 [회원](../product/members.md)에 있다.

## 로그인 흐름

- 웹은 카카오 인가 코드를, 모바일은 카카오 SDK에서 받은 액세스 토큰을 API 서버로 보낸다.
- 서버는 카카오에 사용자 정보를 확인한 뒤 자체 JWT를 발급한다.

## 토큰

- 액세스 토큰은 수명이 짧다.
- 리프레시 토큰은 DB에 저장하고, 쓸 때마다 새 토큰으로 교체한다.
- 토큰 수명의 구체적인 값은 구현자에게 맡긴다.

## 클라이언트별 보관

- 웹은 리프레시 토큰을 HttpOnly 쿠키로 보관한다.
- 모바일은 보안 저장소로 보관한다.
- API 서버는 두 클라이언트를 같은 방식으로 처리한다.

## 카카오 설정

카카오 Redirect URI는 로컬 주소와 `https://pipibooks.com`을 함께 등록한다.
