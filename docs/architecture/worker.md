# 워커

`services/app/worker`는 오래 걸리거나 주기적으로 도는 작업을 맡는 실행 앱이다.

## 실행 방식

- `@Scheduled`로 주기적으로 작업을 실행한다. 작업마다 실행 기록 테이블에 마지막 성공 시점을 남긴다.
- 워커가 켜질 때 실행 기록을 보고, 꺼져 있던 동안 놓친 구간을 따라잡는다.
- 정해진 시각에 반드시 실행되어야 하는 작업은 두지 않는다([서비스 개요](../product/overview.md#반목표)).
- 워커는 단일 인스턴스로 실행한다. 분산 락은 쓰지 않는다.
- 스케줄 주기의 구체적인 값은 구현자에게 맡긴다.

## 작업 목록

- **신간 수집:** 하루 단위 구간으로 수집한다. 실행 기록이 없는 첫 실행은 30일 전부터 수집한다. 수집 대상은 [도서 정보](../product/books.md#신간)를 따른다.
- **데이터 보충:** 표지나 소개글이 비어 있는 도서를 카카오 데이터로 채운다.
- **순위 집계:** TOP 100, 주간·월간 순위, 카테고리별 순위를 계산해서 순위 테이블에 저장한다. 계산 방식은 [도서 정보](../product/books.md)에 있다.
