# 0011. 카드 자동 발행과 사후 점검

- 상태: 승인 · 2026-11-06 (ADR 0005의 "관리자가 초안을 검수·편집해 발행한다"를 대체)

## 맥락
ADR 0005는 모든 카드 초안을 관리자가 검수한 뒤 발행하게 했다. 신간만 해도 한 달에 수천 종이고, 1인 운영에서 발행 전 검수를 고집하면 관리자가 쉬는 동안 피드에 새 카드가 들어오지 않는다. 카드 내용은 출판사 책소개를 옮긴 것이라 유해한 내용이 섞일 위험은 낮다. 오히려 학습참고서처럼 피드에 어울리지 않는 책과 표지 누락이 품질을 좌우한다.

## 결정
- catalog-worker가 초안마다 자동 발행 가능 여부와 걸린 사유를 판정한다. 기준: 소개 100자 이상, 종이책 단권, 부가기호 첫 자리 5·6(학습참고서) 제외, 표지 있음.
- 기준을 통과한 초안은 core가 `AUTO` 카드로 자동 발행한다. 통과하지 못한 초안은 관리자 대기열에 남는다.
- 검수는 발행 후에 한다: 최근 자동 발행 목록, 넘김 비율 점검 목록(이벤트 기반), 일반 공개 시 사용자 신고.
- 신고나 넘김 비율로 카드를 자동으로 숨기지 않는다. 숨김은 관리자가 결정한다.
- 큐레이션 카드(`CURATED`, `QUOTE` 슬라이드)는 계속 관리자가 만들어 발행한다.

## 결과
- 장점: 수집만 돌아가면 피드가 계속 채워진다. 관리자는 문제가 생긴 카드만 처리한다.
- 단점: 잘못된 카드가 잠시 피드에 노출될 수 있다. 판정 기준을 데이터에 맞춰 계속 다듬어야 한다.

## 검토한 대안
- 대기열 + 일괄 발행: 검수 품질은 높지만 관리자가 손을 놓으면 피드가 멈춘다.
- 한 장씩 검수: 하루 발행량이 너무 적다.
- 신고 누적 자동 숨김: 제한 공개 단계에서는 기준값을 정할 데이터가 없다. 일반 공개 후 다시 검토한다.
