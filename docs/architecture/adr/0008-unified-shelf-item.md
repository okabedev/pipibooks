# 0008. 서재 모델 통합(shelf_item)

- 상태: 승인 · 2026-11-05

## 결정
위시와 독서 상태를 별도 테이블로 나누지 않고, `shelf_item`(상태: `WISH`/`READING`/`FINISHED`/`DROPPED`) 하나로 표현한다. (회원, 도서)에 UNIQUE를 건다.

## 이유
- "위시했던 책을 읽기 시작함"이 상태 전이 하나로 끝난다.
- 같은 책이 중복으로 쌓이지 않는다.
- "위시에서 완독까지 걸린 기간" 같은 통계를 바로 낼 수 있다.

## 결과
상태 전이 규칙을 도메인 로직으로 명확히 정의하고 테스트해야 한다.
