# 0009. 세션 간 일관성은 도구로 강제

- 상태: 승인 · 2026-11-05

## 맥락
Claude 세션이 바뀌어도 개발 방식과 컨벤션이 달라지면 안 된다. 문서만으로는 해석의 차이가 생긴다.

## 결정
- 원칙: "문서는 알리고, 도구는 강제한다."
- 매 세션 로드하는 `CLAUDE.md`(루트와 하위, 각 200줄 미만)에 고정 워크플로와 핵심 규칙을 둔다.
- 강제 도구: lefthook(commitlint, 브랜치 이름, ktlint/detekt, ESLint/Prettier, 문서 줄 수), ArchUnit, DB 권한, CI
- Claude 전용 장치: `.claude/settings.json` 훅(포매터 자동 실행, 우회 명령 차단), 프로젝트 스킬, 산출물 템플릿
- 첫 기능을 "표준 예시"로 완성하고 이후 기능은 그 구조를 따른다.

## 결과
초기 도구 설정 비용이 든다(서브프로젝트 0). 대신 이후 작업의 편차가 줄어든다.
