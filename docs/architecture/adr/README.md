# ADR (Architecture Decision Records)

결정의 "이유"를 기록한다. 규칙 자체는 `CLAUDE.md`와 `docs/conventions/`에 둔다.
새 결정은 다음 번호로 추가하고, 기존 결정을 뒤집을 때는 새 ADR을 만들고 옛 ADR의 상태를 `대체됨(NNNN)`으로 바꾼다.

| 번호 | 제목 | 상태 |
|---|---|---|
| 0001 | 모듈러 모놀리스와 분리 컴포넌트 | 승인 |
| 0002 | 백엔드 스택 | 승인 |
| 0003 | 클라이언트 스택 | 승인 |
| 0004 | 인증 방식 | 승인 |
| 0005 | 콘텐츠 원천과 카드 생성 | 승인 |
| 0006 | 단계적 추천 전략 | 승인 |
| 0007 | 로컬 Docker와 Cloudflare Tunnel 배포 | 승인 |
| 0008 | 서재 모델 통합(shelf_item) | 승인 |
| 0009 | 세션 간 일관성은 도구로 강제 | 승인 |
| 0010 | Git Flow와 Public 저장소 | 승인 |

형식: `# NNNN. 제목` / 상태·날짜 / 맥락 / 결정 / 결과(장단점) / 검토한 대안
