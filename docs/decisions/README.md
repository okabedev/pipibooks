# 결정 기록

설계 중이나 진행 중에 내린 결정을 남긴다. 무엇이 승인이 필요한 결정인지는 [결정 방식](../conventions/decision-making.md)에 있다.

## 기록 방법

- 사용자의 승인을 받은 결정만 기록한다.
- 파일 이름은 `000N-<영어-제목>.md`이고 번호는 순서대로 붙인다.
- 이미 기록한 결정이 바뀌면 파일을 고치지 않고 새 번호로 기록한다. 이전 기록의 상태는 `대체됨(→ 000M)`으로 바꾼다.
- 아래 형식을 따른다.

```markdown
# 000N. <결정 제목>

- 날짜: YYYY-MM-DD
- 상태: 채택 | 철회 | 대체됨(→ 000M)

## 배경
## 검토한 안
## 결정
## 결과
```
