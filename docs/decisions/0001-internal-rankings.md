# 0001. 순위는 내부 평가로만 계산

- 날짜: 2026-11-14
- 상태: 채택

## 배경

홈에 보여 줄 인기 순위(피피북스 TOP 100, 주간·월간 인기)의 기준을 정해야 했다.

## 검토한 안

- A: 모두 내부 평가 기반
- B: TOP 100은 내부 평가, 주간·월간은 도서관 정보나루 대출 데이터
- C: 모두 외부 데이터

## 결정

A를 채택한다. 사용자가 피피북스만의 순위를 원했다.

## 결과

- 외부 인기 데이터(도서관 정보나루 등)는 쓰지 않는다.
- 초기에는 평가가 적어 목록이 빌 수 있다. 이 문제는 "아직 평가가 부족해요" 같은 안내 문구로 해결한다.
- 계산 방식은 [도서 정보](../product/books.md)에 있다.
