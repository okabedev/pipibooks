# 0006. v1.0.0 이후 태그

- 날짜: 2026-11-14
- 상태: 채택 (사용자 승인 2026-11-14)

## 배경

Git 규칙은 마일스톤마다 `v0.N.0`, 1차 목표를 마치면 `v1.0.0`이라고 정했다. 1차 목표는 M7에서 끝나므로 M7이 `v1.0.0`이다. 그 뒤의 M8, M9에 `v0.8.0`, `v0.9.0`을 달면 번호가 거꾸로 간다.

## 검토한 안

- **마이너 버전을 올림 (채택):** M8 `v1.1.0`, M9 `v1.2.0`
- **2차 목표 완료를 메이저로:** M8 `v1.1.0`, M9 `v2.0.0`
- **M8 시작 때 결정:** 미정으로 둔다

## 결정

v1.0.0 뒤로는 마일스톤마다 마이너 버전을 올린다. M8은 `v1.1.0`, M9(2차 목표 완료)는 `v1.2.0`이다.

## 결과

- [Git 규칙](../conventions/git.md)과 M8, M9 마일스톤 파일에 반영했다.
