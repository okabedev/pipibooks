# 0004. M0 릴리스와 태그 생략

- 날짜: 2026-11-14
- 상태: 채택 (사용자 승인 2026-11-14)

## 배경

Git 규칙은 마일스톤이 끝날 때마다 `release/*` 브랜치를 거쳐 `main`에 병합하고 `v0.N.0` 태그를 단다고 정했다. 그대로 적용하면 M0는 `v0.0.0`이 된다. 그런데 태그는 보통 출시할 수 있는 버전을 표시하는 데 쓰고, M0의 결과물은 문서뿐이다.

## 검토한 안

- **`v0.0.0`으로 릴리스:** 규칙을 예외 없이 적용한다. 출시할 소프트웨어가 없는데 버전이 생긴다.
- **M0는 릴리스 생략 (채택):** `develop` 병합까지만 한다.

## 결정

M0는 릴리스 브랜치와 태그를 생략하고 `develop` 병합까지만 한다. 첫 태그는 실행 가능한 뼈대가 생기는 M1의 `v0.1.0`이다.

## 결과

- [Git 규칙](../conventions/git.md)에 M0 예외를 적었다.
- M1부터는 규칙대로 마일스톤마다 `v0.N.0`을 단다.
