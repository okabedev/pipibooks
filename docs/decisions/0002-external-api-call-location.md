# 0002. 외부 API 호출 위치

- 날짜: 2026-11-14
- 상태: 채택

## 배경

국립중앙도서관과 카카오 API를 API 서버(`services/app/api`)와 워커(`services/app/worker`) 중 어디서 호출할지 정해야 했다.

## 검토한 안

- **처음 해석 (철회):** "외부 API 호출은 모두 워커가 맡는다"로 해석했다. 이 해석은 철회했다.
- **API 서버가 워커의 내부 API를 거쳐 외부를 호출 (버림):** 워커가 꺼지면 검색도 멈춘다.
- **미리 수집한 책만 검색 (버림):** 수집되지 않은 책은 찾을 수 없다.
- **작업의 성격에 따라 나눔 (채택):** 아래 결정.

## 결정

외부 API 클라이언트(`services/client`)는 라이브러리다. 애플리케이션은 작업의 성격에 따라 나눈다.

- 사용자 요청에 바로 응답해야 하는 작업(검색, 저장되지 않은 책의 상세 조회)은 API 서버가 직접 처리한다.
- 오래 걸리거나 주기적으로 도는 작업은 워커가 처리한다.

## 결과

- API 서버와 워커가 모두 `services/client`에 의존한다([백엔드 모듈](../architecture/backend-modules.md)).
- 워커가 꺼져 있어도 검색과 도서 상세는 동작한다.
- 세부 흐름은 [도서 데이터](../architecture/book-data.md)에 있다.
