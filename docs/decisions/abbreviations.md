# 축약어 목록

사용자가 승인한 축약어만 식별자와 문서에 쓸 수 있다. 허용 기준은 [이름 짓기와 언어](../conventions/naming.md)에 있다.

## 허용 기준

- 고유 명사로 쓰이는 축약: ISBN, KDC, JWT, API 등
- 긴 명칭
- 3 단어 이상으로 이루어진 명칭

허용 기준에 해당하는 축약어도 사용자의 승인을 받고 이 목록에 행을 더한 뒤에 쓴다.
