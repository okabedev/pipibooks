# 0003. 역할별 모듈 구성

- 날짜: 2026-11-14
- 상태: 채택

## 배경

백엔드를 Gradle 멀티 모듈로 나누는 기준을 정해야 했다.

## 검토한 안

- A: 역할별 모듈 (실행 앱, 도메인, 외부 연동, 공통)
- B: 기능별 모듈. 기능 사이 의존성이 얽혀 있어서 이 규모에는 무겁다.
- C: 헥사고날. 단순한 데이터 조회와 저장이 대부분이라 과하다.

## 결정

A를 채택한다. 모듈 이름과 배치는 사용자가 조정했다.

## 결과

- 모듈 구성과 의존 방향은 [백엔드 모듈](../architecture/backend-modules.md)에 있다.
- 기능 구분은 모듈이 아니라 `core` 안의 패키지로 한다.
- 기능별 모듈과 헥사고날은 [반목표](../product/overview.md#반목표)에 들어간다.
