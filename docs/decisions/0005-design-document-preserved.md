# 0005. 원본 설계서 보존

- 날짜: 2026-11-14
- 상태: 채택 (사용자 승인 2026-11-14)

## 배경

원본 설계서 `docs/superpowers/specs/2026-11-14-pipibooks-design.md`는 M0에서 `docs/` 아래 주제별 문서로 나누어 옮기기로 했다. 옮긴 뒤에 원본을 어떻게 할지 정해야 했다.

## 검토한 안

- **기록으로 보존 (채택):** 파일을 남기고 상태를 "승인"으로 고친 뒤 더 이상 고치지 않는다.
- **삭제:** 주제별 문서만 남기고 원본은 Git 이력에만 남긴다.

## 결정

원본 설계서를 기록으로 보존한다. 맨 위에 "이후 기준 문서는 `docs/`의 주제별 문서"라는 안내를 붙인다.

## 결과

- 원본과 주제별 문서가 다르면 주제별 문서가 기준이다.
- 설계가 바뀌면 주제별 문서와 결정 기록을 고친다. 원본 설계서는 고치지 않는다([문서 규칙](../conventions/documentation.md)).
