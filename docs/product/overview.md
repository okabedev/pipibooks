# 서비스 개요

피피북스가 무엇을 위한 서비스인지, 무엇을 하고 무엇을 하지 않는지 정리한다.

## 의도

- 포트폴리오용 풀 스택 서비스다. 지인들에게 가볍게 소개해서 실제로 쓰게 하는 규모다.
- 보여 주려는 것은 백엔드 설계(멀티 모듈, 워커 분리, 외부 연동 모듈화)와 정리된 문서, Git 이력이다.
- 서비스를 24시간 운영할 필요는 없다. 서버가 꺼졌다 켜져도 문제없이 동작하는 것이 기준이다.

## 목표

- **1차 목표:** 백엔드와 웹을 로컬 Docker로 실행하고 Cloudflare Tunnel을 통해 `pipibooks.com`으로 공개한다.
- **2차 목표:** React Native(Expo) 모바일 앱을 만든다. 스토어에는 출시하지 않는다.

목표별 진행 순서는 [로드맵](../roadmap/README.md)에 있다.

## 비목표

대규모 트래픽 대응, 고가용성, 캐시와 메시지 큐, 소셜 기능(팔로우, 남의 책장 구경), 독서 상태 관리, 카카오 외 로그인.

## 반목표

하지 않으려고 피하는 것들이다.

- 규모에 비해 무거운 구조(기능별 모듈, 헥사고날). 이유는 [0003. 역할별 모듈 구성](../decisions/0003-role-based-modules.md)에 있다.
- 정해진 시각에 반드시 실행되어야 하는 작업.
- 의미가 흐려지는 축약어. 기준은 [이름 짓기 규칙](../conventions/naming.md)에 있다.
